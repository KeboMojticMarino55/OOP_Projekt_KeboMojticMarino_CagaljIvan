# TURN-BASED GAME
Igra se pokreće pokretanjem TURN_BASED_GAME_V4.exe datoteke.
Pri pokretanju potrebni su svi dependencies i libraries u folder-u aplikacije.

------------------------------------------------------------------------------

Main menu ima 2 botuna, Start Game za pokretanje igre i Exit Game za gasenje iste.

Nakon pritiska na Start Game otvara se Character Select ekran gdje se biraju likovi za nas team.

U sredini teama mora biti Dantus.

DPSov ability je raditi vise damage-a, Healerov ability je healati nekoga, Amplifierov ability je pojacati neciji napad i Shielderov ability je dati shield nekome.

Nakon ulaska u bitku s lijeve strane prikazan je nas team, s desne strane enemy i u sredini je Battle Log. U donjem lijevom kutu su prikazani Ability Points i ciji je turn trenutno. Dolje lijevo se takoder nalaze botuni za Normal Attack, Ability i Ultimate. Koristenjem Normal Attack-a dobijamo jedan Ability point, koristenjem Ability-a trosimo jedan Ability point. Ability se ne moze aktivirati ako nemamo vise Ability points. Takoder, koristenjem Normal Attack-a taj lik dobija 20% Ultimate Charge-a, a koristenjem Ability-a dobija 60%. Ultimate moze iskoristiti kada je Ultimate Charge 100%.

Tijekom cijele borbe se u Battle Log-u ispisuje sve sto se dogada.

Pobjeda se ostvaruje pobjedom svih 7 enemy-a, a igrac gubi ukoliko Dantus umre, neovisno jesu li druga 2 lika u team-u ziva.
